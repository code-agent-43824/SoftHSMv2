# ROADMAP — куда идёт проект

## Продукт

Портируемый PKCS #11-модуль, который выдаёт себя за Рутокен ECP. Нужен, чтобы
тестировать ПО, работающее с Рутокен ECP, там, где физический токен вставить
некуда: облачный сервер, раннер CI, машина разработчика без доступного USB.

Форк `opendnssec/SoftHSMv2` от коммита `f12916e`. Форк тупиковый: наверх ничего
не отдаём, сверху ничего не берём, совместимость с апстримом ни на что не влияет.

Отсюда три свойства, ради которых всё и делается:

1. **Разворачивается распаковкой архива** — без установщика, без прав
   администратора, без внешних зависимостей в системе.
2. **Ведёт себя одинаково везде** — одна пользовательская конфигурация и одно
   хранилище токенов независимо от того, куда распакован модуль и какой
   разрядности процесс его загрузил.
3. **Говорит по-ГОСТу** — Стрибог-256 и ГОСТ Р 34.10-2012/256 с
   идентификаторами механизмов ТК-26, потому что без них ПО под Рутокен не
   поедет.

## Этапы

| # | Этап | Состояние |
| --- | --- | --- |
| 1 | Портируемые сборки: Linux x64/ARM64, Windows x86/x64/ARM64, macOS universal; статический OpenSSL | Закрыт |
| 2 | ГОСТ 2012: Стрибог-256, генерация и подпись ГОСТ Р 34.10-2012/256 | Закрыт |
| 3 | Вендор-нейтральный e2e-тест PKCS #11, тест-киты, проверка архивов на чистых раннерах | Закрыт |
| 4 | Профиль совместимости `FAKE_RUTOKEN_ECP` | Закрыт |
| 5 | Приведение репозитория к правилам `AGENTS.md` | Закрыт |
| 6 | Проверка портируемых сборок Windows на живом стенде | Закрыт |
| 7 | Юнит-тесты на код ГОСТ 2012 | Текущий |
| 8 | Проверка профиля `FAKE_RUTOKEN_ECP` на реальном ПО под Рутокен ECP | Не начат |
| 9 | Расширение `C_EX_*`: дореализация функций по мере надобности | Не начат |

Этапы 1–4 закрыты по факту работы, выполненной до появления этих документов;
их содержание восстановлено по истории коммитов и коду, а не по плану.

Этап 8 записан как понимание агента и **владельцем ещё не подтверждён** —
состав и срок могут измениться.
